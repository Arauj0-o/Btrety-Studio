# Btrety Studio

**Btrety Studio** é um ambiente de desenvolvimento (IDE) leve que tem um sistema projetado para converter a linguagem **Bcode** (Usada pelo Btrety Studio) para linguagens já conhecidas como Python, Java e C++.

### 🛠 Diferenças:
- **Fácil de usar**: Usa palavras do Português Brasileiro como: "escrever", "se", "digitar", etc.
- **Tradução de Linguagens (Beta)**:
  - **Importação**: Converta códigos existentes (.py, .java ou .cpp) para Bcode.
  - **Exportação**: Escreva em Bcode e gere arquivos prontos para rodar em Python, Java (com Scanner) ou C++ (com iostream).
- **Paleta de Cores**: Ferramenta HEX integrada para design.
- **Leve para baixar**: Com apenas cerca de 200MB livres você já instala o Btrety Studio
- **Open-source**: Baixe o [código fonte](https://github.com/) na aba Realeases e modifique do seu jeito.

### 📥 Instalação
1. Baixe o instalador na aba [Releases](https://github.com/).
2. Execute o `Btrety Studio-Setup-1.0.0.exe`.
3. Se escolher adicionar um ícone na Área de Trabalho, adicione-o manualmente, pois o Windows Defender não deixa adicionar atalhos na Área de Trabalho sem uma Assinatura Digital, oque seria muito caro, principalmente pra um projeto totalmente gratuito.

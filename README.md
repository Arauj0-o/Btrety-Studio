# Btrety Studio

O **Btrety Studio** é um ambiente de desenvolvimento (IDE) leve, projetado para converter a linguagem **Bcode** (nativa da plataforma) para linguagens consolidadas como Python, Java e C++.

### 🛠 Diferenciais
- **Fácil de usar**: Utiliza sintaxe baseada no Português Brasileiro, com comandos intuitivos como "escrever", "se", "digitar", entre outros.
- **Tradução de Linguagens (Beta)**:
  - **Importação**: Converta códigos existentes (`.py`, `.java` ou `.cpp`) diretamente para Bcode.
  - **Exportação**: Escreva em Bcode e gere arquivos prontos para execução em Python, Java (utilizando Scanner) ou C++ (utilizando iostream).
    - **Nota**: Na versão `Btrety Studio (Beta 1)`, a exportação para outras linguagens está indisponível, em breve será possível.
- **Paleta de Cores**: Ferramenta HEX integrada para auxiliar no design.
- **Instalação leve**: Requer apenas cerca de 200 MB de espaço livre em disco.
- **Código aberto (Open Source)**: Acesse o [código-fonte](https://github.com/Arauj0-o/Btrety-Studio/releases) na aba *Releases* e contribua com o projeto.

### 📥 Instalação
1. Baixe o instalador na aba [Releases](https://github.com/Arauj0-o/Btrety-Studio/releases).
2. Execute o arquivo `Btrety Studio-Setup-1.0.0.exe` e siga as instruções na tela.
3. **Sobre o atalho**: Caso queira criar um ícone na Área de Trabalho, adicione-o manualmente. Por ser um projeto independente e sem fins lucrativos, o instalador ainda não possui uma Assinatura Digital paga. Por esse motivo, o Windows Defender pode bloquear a criação automática de atalhos por segurança.

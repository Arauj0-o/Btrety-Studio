Tabela de Funções — Bcode✕
Saída
escrever("texto")Exibe texto no console.
escrever("§colorhex=#RRGGBB§texto§§")Texto colorido. §§ reseta a cor.
escrever("..variavel..")exibe o valor da variavel.
cor(#RRGGBB)Define cor global do texto até mudar novamente.
limpar()Limpa todo o console.
Entrada
digitar = (variavel)Lê qualquer valor e salva na variável.
digitar <a, b, c> = (variavel)Só aceita os valores listados. Exibe erro se inválido.
Tempo & Data
data()Exibe hora atual no console.
data(registrar=h) variavelGuarda a hora (0–23) na variável.
data(registrar=d) variavelGuarda o dia do mês (1–31) na variável.
data(registrar=m) variavelGuarda o mês (1–12) na variável.
data(registrar=a) variavelGuarda o ano (ex: 2026) na variável.
esperar(ms)Pausa a execução pelo tempo em milissegundos.
Variáveis & Cálculo
variavel nome = valorCria ou altera uma variável.
calc(var = expressão)Calcula (+, -, *, /) com suporte a variáveis.
..variavel..Interpola o valor de uma variável dentro de escrever().
Controle de Fluxo
se (condição) { }Executa o bloco se a condição for verdadeira.
senao { }Bloco executado quando o se anterior for falso.
T1 / T2 / T3...Define um marcador de posição no código (label).
rT1 / rT2 / rT3...Volta ao tópico correspondente (cria um loop).
Sistema
terminal()Modo interativo direto. Digite 'sair' para encerrar.
rnm orig=novo; orig2=novo2Renomeia funções. Deve ser a última linha do arquivo.

Atualizar Btrety Studio ✕

Se estiver utilizando o Nativefier: No momento, não é possível atualizar o Btrety Studio de forma automatizada. Para realizar a atualização, acesse o nosso repositório no GitHub e compare a versão mais recente liberada com a versão que você possui instalada. Se estiver utilizando pela Web: Você já está o mais atualizado possivel, quando lançar novas atualizações, você receberá automaticamente.

Para verificar a versão atualmente instalada em sua máquina, acesse o menu "Mais" e clique em "Sobre".
